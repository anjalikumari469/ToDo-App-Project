# 📝 Todo App

A simple and interactive Todo App built using HTML, CSS, and JavaScript. It helps users organize their daily tasks efficiently with a clean and responsive interface.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Dark Mode support
- Responsive design
- Easy-to-use interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🎯 Learning Outcomes

- DOM Manipulation
- Event Handling
- JavaScript Fundamentals
- Responsive Design
- UI Development
